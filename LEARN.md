# Talk to PDF 🤖 📑️

An intelligent document interaction system that enables natural language conversations with PDF documents. Powered by OpenAI's language models and built with Streamlit, this application allows users to extract insights and information from PDFs through simple questions and answers.

## 🚀 Features

- Natural language interaction with PDF documents
- Real-time AI-powered responses
- Support for multiple PDF uploads
- Context-aware conversation system
- Customizable AI model parameters
- User-friendly interface
- Streaming responses for better UX

## 📋 Prerequisites

- Python 3.11 or higher
- OpenAI API key
- Modern web browser
- Internet connection

## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/talk-to-pdf.git
cd talk-to-pdf
```

2. Install required packages:
```bash
pip install -r requirements.txt
```

## 🎯 Usage

### 1. API Key Setup
- Launch the application
- Navigate to the API key section
- Get your OpenAI API key from [OpenAI Platform](https://platform.openai.com/account/api-keys)
- Enter the API key in the secure input field
- Click "Submit" to save your key

### 2. Document Upload
- Go to the PDF upload section
- Click "Browse Files" or drag and drop your PDF
- Wait for the upload and processing to complete
- Multiple PDFs are supported

### 3. Asking Questions
- Type your question in the chat input box
- Click "Send" or press Enter
- The AI will analyze the document and provide relevant answers
- Continue the conversation naturally with follow-up questions

### 4. Customization Options
- Select between GPT-3.5 and GPT-4 models
- Adjust temperature settings for response variety
- Modify other parameters as needed

## 🔧 Technical Details

- Built with Streamlit for the web interface
- Uses LlamaIndex for document processing
- Implements OpenAI's language models
- Features real-time response streaming
- Maintains conversation context
- Secure API key handling
